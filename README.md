## 🎯 Overview

**AI PDF Chatbot with Advanced RAG** is a question-answering system that lets users upload PDF documents and converse with them. It utilizes an advanced Retrieval-Augmented Generation (RAG) architecture featuring **Hybrid Search** (combining Dense Chroma vector search with Sparse BM25 keyword search), **Reciprocal Rank Fusion (RRF)**, and **Cross-Encoder Reranking**. This ensures highly accurate and context-aware answers generated by Google Gemini, all wrapped in an interactive Streamlit frontend.

### Key Capabilities

- **Hybrid Search**: Combines semantic vector search (Chroma) with exact keyword matching (BM25) for comprehensive retrieval.
- **Cross-Encoder Reranking**: Uses `ms-marco-MiniLM-L-6-v2` to evaluate and re-score top candidate chunks, ensuring the highest relevance.
- **Google Gemini Integration**: Utilizes Gemini 2.5 Flash for accurate embeddings and natural language generation.
- **Tunable Retrieval**: Adjust the balance between dense and sparse search using a configurable `alpha` parameter.

## 🏗️ System Architecture

```text
┌─────────────────────────────────────────────────────────┐
│                    Web Frontend                         │
│               (Streamlit UI - app.py)                   │
│   [Upload PDF]   [Settings Sidebar]   [Chat Interface]  │
└───────────────────────────┬─────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│               Data Ingestion & Indexing                 │
│ • PyPDF2: Extract text from PDF                         │
│ • TextSplitter: Break text into 1000-char chunks        │
│ • Indexing:                                             │
│     ├─► Dense: Gemini Embeddings -> Chroma Vector DB    │
│     └─► Sparse: Tokenization -> BM25 Keyword Index      │
└───────────────────────────┬─────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│               Hybrid Retrieval Pipeline                 │
│ • User Query triggers parallel searches:                │
│     ├─► Dense Search (Chroma) -> Top K Semantics        │
│     └─► Sparse Search (BM25)  -> Top K Keywords         │
│ • Reciprocal Rank Fusion (RRF): Combines and ranks      │
│   both result sets using tunable 'alpha' weight         │
└───────────────────────────┬─────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│                 Cross-Encoder Reranking                 │
│ • Model: ms-marco-MiniLM-L-6-v2                         │
│ • Re-evaluates top RRF candidates against the query     │
│ • Selects the absolute Top-N most relevant chunks       │
└───────────────────────────┬─────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│                LLM Synthesis (Gemini)                   │
│ • Injects Top-N chunks + User Query into Prompt         │
│ • Gemini 2.5 Flash generates context-aware answer       │
│ • Returns Answer + Source Chunks to Frontend            │
└─────────────────────────────────────────────────────────┘
```

### Data Flow

1. **Data Ingestion**: Uploaded PDFs are parsed, split into chunks, and indexed into both a **Chroma Vector Store** (dense embeddings) and a **BM25 Index** (sparse keywords).
2. **Hybrid Retrieval**: User queries trigger simultaneous dense and sparse searches.
3. **Reciprocal Rank Fusion (RRF)**: Results from both searches are mathematically fused using a tunable `alpha` weight.
4. **Cross-Encoder Reranking**: The top candidates from RRF are re-evaluated by a cross-encoder model to determine their true relevance to the query.
5. **LLM Synthesis**: The highest-scoring chunks are injected into a prompt and sent to Gemini 2.5 Flash to generate the final response.
6. **Display**: The answer and the retrieved source chunks (with their reranker scores) are shown to the user.

## 📦 Setup & Usage

**Prerequisites**: Python 3.10+ and a [Google Gemini API Key](https://aistudio.google.com/).

```bash
git clone https://github.com/yourusername/chatbot-with-RAG.git
cd chatbot-with-RAG
python -m venv venv && source venv/bin/activate  # Or .\venv\Scripts\activate on Windows
pip install -r requirements.txt
echo "GOOGLE_API_KEY=your_key_here" > .env
streamlit run app.py
```
